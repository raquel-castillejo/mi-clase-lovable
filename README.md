## Descripción 📑

El objetivo de este proyecto es plantear una app que ayude a los profesores a memorizar los nombres de sus nuevos alumnos, en especial a principios del curso escolar, cuando se incorporan muchas clases nuevas. El briefing del proyecto viene de la [lista semanal de ejercicios de Artiom Dashinsky](https://productdesigninterview.com/weekly-ux-product-design-exercise).

Como objetivo personal, mi meta es realizar esta propuesta incorporando distintas herramientas de IA a lo largo de mi proceso de trabajo. Las herramientas que estoy utilizado son:
- Claude Desktop
- Lovable
- Figma

## ¿Qué estoy aprendiendo en este proyecto? 🙇🏻

Este proyecto sigue en curso y no lo considero terminado. Algunos de mis aprendizajes hasta ahora son:
- Cómo conectar Claude Desktop con Figma, Lovable y Github.
- Cómo plantear un Design System (DS) en Lovable y generar un prototipo a partir del DS.
- Cómo pasar prompts a Claude para que genere tokens y componentes en Figma a partir de lo experimentado en Lovable.
- (Aprendizaje en proceso) Optimizar los prompts y las peticiones para sacarle partido a los créditos diarios de cada IA. Encuentro que son muy pocos créditos para experimentar con tranquilidad.
